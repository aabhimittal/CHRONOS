CHRONOS Fleet Simulator

CHRONOSDeadline-aware GPU serving for fleets of vision-language-action robots

Each robot runs a slow planner (a vision-language model) and a fast action head that must answer every control tick. Share one GPU across the fleet and two things can go wrong: actions miss their deadline, or plans go stale. Move the sliders to see which one breaks first under each scheduler.

Each row is reproducible with the script named in the README. "Hurts" rows are kept on purpose: they mark ideas that sounded right and failed in simulation.

Everything on this page comes from simulation. The staleness curves come from a toy moving-target task, and the GPU latency constants are illustrative, not profiled. These numbers show how the effects behave, not what a real fleet will do.

The page runs a JavaScript port of the Python simulator, and a test checks it matches the Python to 1e-6. Code, tests and caveats: github.com/aabhimittal/CHRONOS.
